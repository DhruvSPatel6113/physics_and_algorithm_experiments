# Newton's Cradle Bobs Simulation

> Physics-based 5-bob Newton Cradle pendulum simulation demonstrating momentum conservation and constraints in Matter.js

## Overview
An interactive physics experiment simulating a classic 5-bob Newton's Cradle. Built using **Matter.js**, it demonstrates elastic collision physics, kinetic energy propagation, and linear constraints.

## Features
- **5-Bob Array**: Five identical suspended spheres with configured restitution and density properties.
- **Rigid Constraints**: Modeled using `Matter.Constraint` with customized stiffness and string length.
- **Interactive Impulse**: Drag and release the outer bob to watch momentum transfer through the stationary central spheres.

## Tech Stack
- **JavaScript**
- **Matter.js** (Physics engine & constraints)
- **p5.js** (Canvas rendering)
