# Ballistic Bullet Penetration

> Bullet velocity and material thickness penetration simulation

## Overview
An interactive physics simulation and creative coding experiment exploring rigid-body mechanics, particle dynamics, and collision algorithms built with **Matter.js** and **p5.js**.

## Core Concepts Explored
- **Rigid-Body Physics**: Modeling mass, velocity, restitution, and friction properties.
- **Collision Dynamics**: Accurate detection and reaction between dynamic and static bodies.
- **Interactive Controls**: Real-time user input via mouse constraints and keyboard interactions.

## Tech Stack
- **JavaScript (ES6+)**
- **Matter.js** (2D physics simulation library)
- **p5.js** (Creative coding & canvas rendering)

## Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/DhruvSPatel6113/ballistic_bullet_penetration.git
   cd ballistic_bullet_penetration
   ```
2. Open `index.html` directly in any web browser.
